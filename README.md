# Ibach Pool by the Sea 2026 — Free Live Bracket

This package uses:
- GitHub Pages Free for the public website
- Supabase Free for one shared live database
- Supabase email/password authentication for the tournament administrator

Files:
- `index.html` — tournament website
- `config.js` — paste your Supabase URL and anon key here
- `supabase-setup.sql` — creates the shared bracket table and security rules

Important: keep the GitHub repository public, do not buy a custom domain, do not upgrade either service, and do not add billing information.
